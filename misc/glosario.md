# Glosario

| Término | Qué es |
|---|---|
| HAOS | Home Assistant OS, el sistema completo con complementos |
| Entidad | Cada objeto que Home Assistant conoce: una luz, un sensor |
| Integración | El módulo que conecta HA con un fabricante o protocolo |
| Automatización | Regla de disparador, condición y acción |
| Escena | Conjunto de estados que se aplica de golpe |
| Complemento | Aplicación que corre dentro de HAOS (Mosquitto, Frigate) |
| HACS | Instalador de integraciones y tarjetas de la comunidad |
| ESPHome | Firmware que se configura con YAML y se integra con HA |
| OTA | Actualización del firmware por la red |
| Deep sleep | Modo de bajo consumo del módulo |
| GPIO | Pin de entrada o salida de propósito general |
| I2C | Bus de dos hilos para sensores y pantallas |
| SPI | Bus rápido para pantallas, tarjetas y radio |
| MQTT | Protocolo de mensajes ligero para dispositivos |
| SBC | Placa de un solo ordenador, como Raspberry Pi |
| HA Container | Home Assistant en Docker, sin complementos |
| Supervised | Instalación con complementos sobre un Linux propio, no soportada |
